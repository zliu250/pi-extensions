# Security

These extensions run with full user permissions inside Pi, and `pi-dump-session` deletes files (exactly one: the current session's file).

If you find a vulnerability — e.g. a way to make an extension delete something it shouldn't, or execute unintended code — please report it privately via [GitHub Security Advisories](https://github.com/zliu250/pi-extensions/security/advisories/new) rather than a public issue. You should receive a response within a few days.
